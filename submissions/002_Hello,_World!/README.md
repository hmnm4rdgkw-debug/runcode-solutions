# 2. Hello, World!

**난이도:** ★

## 문제

화면에 Hello, World! 를 출력하고 줄을 바꾸세요.

[입력] 없음
[출력]
Hello, World!

## 내 코드

```c
#include <stdio.h>

int main(void) {
printf("Hello, World!");
    return 0;
}
```

## 모범 답안

```c
#include <stdio.h>
int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```
